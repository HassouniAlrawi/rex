# rex
REX   هي أداة تُستخدم لإرسال طلبات  متكررة إلى المواقع الإلكترونية، ويمكن استخدامها لاختبار تحمّل الخوادم، كما يمكن إساءة استخدامها لتنفيذ هجمات حجب الخدمة (DoS) التي قد تسبب بطء الموقع أو تعطّله. استخدمها قانونيًا على مختبر تدريبي أو موقع تملكه أو لديك تصريح باختباره. يتحمل المستخدم مسؤولية استخدام الأداة والالتزام بالقوانين.
