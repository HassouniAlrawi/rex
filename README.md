# rex
REX 
هي أداة تُستخدم لإرسال طلبات  متكررة إلى المواقع الإلكترونية، ويمكن استخدامها لاختبار تحمّل الخوادم، كما يمكن إساءة استخدامها لتنفيذ هجمات حجب الخدمة (DoS) التي قد تسبب بطء الموقع أو تعطّله. استخدمها قانونيًا على مختبر تدريبي أو موقع تملكه أو لديك تصريح باختباره. يتحمل المستخدم مسؤولية استخدام الأداة والالتزام بالقوانين.

REX 
— دليل التثبيت والاستخدام على Windows

1. نبذة عن الأداة

REX Terminal
هي أداة مكتوبة بلغة Python، مخصصة لإرسال طلبات
HTTP/HTTPS
إلى عنوان محدد، وعرض نتائج الاتصالات وأزمنة الاستجابة داخل نافذة Terminal بتصميم أخضر وأسود.

المميزات

- واجهة طرفية بتصميم واضح.
- إدخال رابط الموقع يدويًا.
- تحديد عدد الطلبات المراد تنفيذها.
- عرض حالة كل طلب ورقم الاستجابة HTTP.
- قياس زمن استجابة كل طلب بالميلي ثانية.
- عرض شريط تقدم مباشر أثناء التشغيل.
- إظهار ملخص نهائي يتضمن عدد الطلبات الناجحة والفاشلة ومتوسط زمن الاستجابة.
- لا تحتاج إلى مكتبات Python خارجية إضافية وفقًا للنسخة الحالية.

2. متطلبات التشغيل

قبل تثبيت الأداة، تأكد من توفر المتطلبات التالية:

المتطلب| التفاصيل
نظام التشغيل| Windows 10 أو Windows 11
لغة البرمجة| Python 3
الطرفية| PowerShell أو CMD
الاتصال بالإنترنت| مطلوب عند اختبار عنوان ويب
المكتبات الإضافية| غير مطلوبة في النسخة الحالية

3. تثبيت Python على Windows

إذا لم تكن لغة Python مثبتة على جهازك، اتبع الخطوات التالية:

1. افتح الموقع الرسمي:
   https://www.python.org/downloads/windows/
2. نزّل إصدار Python 3 المناسب لنظامك.
3. شغّل ملف التثبيت.
4. فعّل خيار Add Python to PATH إذا ظهر ضمن خيارات التثبيت.
5. أكمل التثبيت.

التأكد من نجاح التثبيت

افتح PowerShell من قائمة Start، واكتب:

py --version

إذا ظهر رقم إصدار Python، فهذا يعني أن المشغّل متوفر.

إذا لم يعمل الأمر السابق، جرّب:

python --version

إذا لم يظهر رقم إصدار في الحالتين، تحقق من تثبيت Python وإضافته إلى PATH.

4. تنزيل ملفات الأداة

نزّل ملف المشروع المضغوط من مستودع GitHub الخاص بالأداة، ثم:

1. افتح مجلد Downloads.
2. استخرج محتويات الملف المضغوط باستخدام Extract All.
3. افتح المجلد الناتج.
4. تأكد من وجود الملفات التالية:

rex-terminal/
├── README.txt
├── install.ps1
├── rex.cmd
├── rex.py
└── uninstall.ps1

مهم: لا تشغّل ملفات المشروع قبل التأكد من مصدرها ومراجعة محتوياتها.

5. تثبيت الأداة على Windows

بعد استخراج الملفات، افتح مجلد "rex-terminal" في مستكشف الملفات.

انقر على شريط العنوان، واكتب:

powershell

ثم اضغط Enter لفتح PowerShell داخل المجلد نفسه.

نفّذ أمر التثبيت التالي:

powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1

ماذا يفعل أمر التثبيت؟

- يتحقق من توفر Python.
- ينشئ مجلدًا خاصًا بالأداة داخل مجلد المستخدم المحلي.
- ينسخ ملفات التشغيل المطلوبة إلى المجلد الجديد.
- يضيف مجلد الأداة إلى متغير البيئة PATH الخاص بالمستخدم.
- يحاول تشغيل الأداة بعد اكتمال التثبيت.

يستخدم أمر التثبيت "ExecutionPolicy Bypass" لهذه العملية فقط؛ لذلك لا يعني هذا الأمر تغيير سياسة التنفيذ بصورة دائمة على مستوى النظام.

6. تشغيل الأداة بعد التثبيت

بعد نجاح التثبيت، أغلق نافذة PowerShell وافتح نافذة جديدة، ثم اكتب:

rex

إذا لم يتعرف Windows على الأمر مباشرة، جرّب تسجيل الخروج والدخول مجددًا أو إعادة تشغيل الطرفية، ثم تحقق من إضافة مجلد الأداة إلى PATH.

يمكنك أيضًا تشغيلها مباشرةً من مجلد التثبيت:

& "$env:LOCALAPPDATA\REX\rex.cmd"

7. طريقة استخدام الأداة

عند تشغيل REX، تظهر واجهة طرفية تتضمن عنوان الأداة ومراحل التنفيذ.

الخطوة الأولى: إدخال الرابط

سيظهر الحقل التالي:

Target URL >

أدخل عنوان موقع تملكه أو لديك إذن باختباره، مثل:

https://example.com

تتحقق الأداة من أن الرابط يبدأ بـ "http://" أو "https://" وأنه يحتوي على اسم مضيف.

هذا التحقق لا يثبت أن الموقع متاح أو أنك مخوّل باختباره.

الخطوة الثانية: تحديد عدد الطلبات

سيظهر الحقل:

Number of requests >

أدخل عدد الطلبات التي تريد تنفيذها ضمن اختبار مصرح به.

الحد الأقصى الموجود في النسخة الحالية هو 10,000 طلب. ابدأ باختبار محدود على بيئة تجريبية تملكها، ولا تستخدم أعدادًا كبيرة قبل التأكد من أن الخادم قادر على تحمل الاختبار.

الخطوة الثالثة: متابعة التنفيذ

أثناء التشغيل، تعرض الأداة معلومات مثل:

- رقم الطلب.
- نتيجة التنفيذ.
- رمز حالة HTTP.
- زمن الاستجابة بالميلي ثانية.
- عدد الطلبات المكتملة.
- الوقت المنقضي منذ بدء الاختبار.

تُنفَّذ الطلبات باستخدام اتصالات متزامنة، ويصل الحد الأقصى للتزامن في النسخة الحالية إلى 50 اتصالًا.

الخطوة الرابعة: قراءة التقرير النهائي

بعد انتهاء التنفيذ، يظهر تقرير يتضمن الحقول التالية:

الحقل| معناه
COMPLETED| عدد الطلبات التي اكتملت معالجتها
SUCCESS| عدد النتائج التي اعتبرتها الأداة ناجحة
FAILED| عدد النتائج التي اعتبرتها فاشلة
AVERAGE| متوسط زمن الاستجابة
FASTEST| أقصر زمن استجابة مسجل
SLOWEST| أطول زمن استجابة مسجل
DURATION| المدة الإجمالية للتنفيذ بالثواني

تعتمد الأداة في تصنيف النتيجة الناجحة على استلام رمز HTTP بين 200 و399. أما الأخطاء والاستثناءات فتظهر ضمن النتائج الفاشلة، وقد يظهر رمز HTTP مثل 404 أو 500 بوصفه نتيجة مستلمة وليست بالضرورة خطأ اتصال.

8. فهم زمن الاستجابة

يقاس زمن الاستجابة بالميلي ثانية (ms).

- 100 ms = 0.1 ثانية.
- 500 ms = 0.5 ثانية.
- 1,000 ms = ثانية واحدة.

ارتفاع زمن الاستجابة أثناء الاختبار قد يرتبط بضغط الخادم، أو الشبكة، أو زمن معالجة الطلب، أو عوامل أخرى.

لا يمكن الحكم على أداء الموقع من زمن استجابة واحد فقط. للحصول على نتائج موثوقة، قارن الاختبارات ضمن ظروف متشابهة، وراقب موارد الخادم وسجلاته، وميّز بين زمن الشبكة وزمن معالجة التطبيق.

9. إيقاف الأداة

يمكن محاولة إيقاف التنفيذ باستخدام:

Ctrl + C

تحاول الأداة إلغاء المهام التي لم تبدأ، لكنها تنتظر انتهاء الاتصالات النشطة أو انتهاء مهلتها قبل إغلاق مجموعة التنفيذ؛ لذلك قد لا يكون الإيقاف فوريًا.

10. حل المشاكل الشائعة

المشكلة الأولى: Python غير مثبت

إذا ظهرت رسالة تطلب تثبيت Python 3:

1. ثبّت Python من الموقع الرسمي.
2. افتح نافذة PowerShell جديدة.
3. تحقق من الإصدار.
4. أعد تشغيل ملف "install.ps1".

المشكلة الثانية: الأمر "rex" غير معروف

تحقق من وجود المجلد:

%LOCALAPPDATA%\REX

ثم تحقق من أن مساره مضاف إلى PATH الخاص بالمستخدم. افتح نافذة طرفية جديدة بعد التعديل.

المشكلة الثالثة: تعذّر الاتصال بالموقع

قد يكون السبب أحد الأمور التالية:

- عدم توفر اتصال بالإنترنت.
- كتابة رابط غير صحيح.
- تعذر الوصول إلى الخادم.
- انتهاء مهلة الاتصال.
- وجود مشكلة في DNS أو شهادة TLS أو إعدادات الشبكة.
- حظر الطلبات أو تقييدها من جهة الخادم.

تحقق من الرابط والاتصال أولًا، واستخدم موقعًا تجريبيًا مصرحًا به.

المشكلة الرابعة: ظهور رموز أو ألوان غير صحيحة

جرّب تشغيل الأداة في Windows Terminal أو إصدار حديث من PowerShell، وتأكد من أن الطرفية تدعم رموز ANSI.

11. إزالة الأداة

إذا أردت حذف الأداة، افتح PowerShell داخل المجلد الذي يحتوي على "uninstall.ps1"، ثم نفّذ:

powershell -NoProfile -ExecutionPolicy Bypass -File .\uninstall.ps1

يحذف برنامج الإزالة مجلد الأداة من مجلد المستخدم المحلي، ويزيل مساره من PATH الخاص بالمستخدم.

لا يحذف هذا الأمر Python من الجهاز، ولا يحذف ملفات المشروع الأصلية التي نزّلتها.

12. ملاحظات أمنية وأخلاقية

- استخدم الأداة فقط على المواقع والأنظمة التي تملكها أو لديك تصريح صريح لاختبارها.
- لا تستخدمها لإغراق المواقع بالطلبات أو تعطيل الخدمات.
- ابدأ بأحمال منخفضة على بيئة اختبار، وحدد سقفًا واضحًا للطلبات ومعدل الإرسال.
- لا تعتبر عدد الطلبات وحده مقياسًا كافيًا لأداء الموقع.
- اختبارات الحمل الاحترافية تحتاج إلى قياس معدل الطلبات الفعلي، ونسب الأخطاء، وزمن الاستجابة عند مستويات مختلفة من الحمل، مع مراقبة موارد الخادم.
